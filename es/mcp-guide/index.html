Guía de Integración MCP de PicEte

Usa las herramientas de procesamiento de imágenes de PicEte desde Claude Code, Cursor, Claude Desktop o cualquier cliente de IA compatible con MCP.

¿Qué es MCP?

Model Context Protocol (MCP) es un estándar abierto que permite a los agentes de IA (como Claude Code, Cursor) llamar herramientas externas directamente. Con picete-mcp, tu IA puede procesar imágenes — comprimir, convertir, redimensionar, extraer colores — sin salir de tu terminal y sin subir nada a ningún servidor.

Todo el procesamiento se ejecuta localmente mediante Sharp. Cero datos salen de tu máquina. La misma garantía de privacidad que PicEte.

Inicio Rápido

Instala y ejecuta con un solo comando (sin registro, no requiere configuración para probar):

npx -y picete-mcp

npm Paquete: picete-mcp@1.0.0

Configuración por Plataforma

Añade lo siguiente a la configuración MCP de tu cliente de IA:

Claude Desktop

Edita claude_desktop_config.json:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Cursor

Edita .cursor/mcp.json en la raíz de tu proyecto:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Claude Code

Edita ~/.claude/settings.json:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

picete-mcp proporciona 13 herramientas en dos categorías:

resizeRedimensionar imagensource, width, height, fit, keep_aspect_ratio
compressComprimir tamaño de archivosource, quality, target_format, max_size_bytes

split-imageDividir en mosaico de cuadrículasource, rows, cols, overlap_px
metadataObtener metadatos de imagensource
batchEncadenar múltiples operacionessources[], operations[]

Herramientas Inteligentes

HerramientaFunciónParámetros Clave

Desarrollo

# Clonar y compilar
git clone https://github.com/0000wei/picete-mcp.git
cd picete-mcp
npm install
npm run build

# Iniciar el servidor MCP
npm start
