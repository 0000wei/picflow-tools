PicEte MCP Guia de Integração

Use as ferramentas de processamento de imagem do PicEte a partir do Claude Code, Cursor, Claude Desktop ou qualquer cliente de IA compatível com MCP.

O que é MCP?

Model Context Protocol (MCP) é um padrão aberto que permite que agentes de IA (como Claude Code, Cursor) chamem ferramentas externas diretamente. Com o picete-mcp, sua IA pode processar imagens — comprimir, converter, redimensionar, extrair cores — sem sair do terminal e sem enviar nada para nenhum servidor.

Todo o processamento é executado localmente via Sharp. Zero dados saem da sua máquina. A mesma garantia de privacidade do PicEte.

Início Rápido

Instale e execute com um único comando (sem cadastro, sem configuração necessária para testes):

npx -y picete-mcp

npm Pacote: picete-mcp@1.0.0

Configuração por Plataforma

Adicione o seguinte à configuração MCP do seu cliente de IA:

Claude Desktop

Edite o claude_desktop_config.json:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Cursor

Edite o .cursor/mcp.json na raiz do seu projeto:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Claude Code

Edite o ~/.claude/settings.json:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Ferramentas Disponíveis

picete-mcp oferece 13 ferramentas em duas categorias:

Ferramentas Atômicas

FerramentaFunçãoParâmetros Principais
convertConversão de formatosource, format (jpeg/png/webp/gif), quality
resizeRedimensionar imagemsource, width, height, fit, keep_aspect_ratio
compressComprimir tamanho do arquivosource, quality, target_format, max_size_bytes
extract-colorsExtrair cores dominantessource, color_count (padrão 5)
image-to-base64Converter para base64/data URLsource, format, data_url
split-imageDividir em grade de tilessource, rows, cols, overlap_px
metadataObter metadados da imagemsource
batchEncadear múltiplas operaçõessources[], operations[]

Ferramentas Inteligentes

FerramentaFunçãoParâmetros Principais
optimize-for-webOtimização web com um cliquesource, max_width, quality, output_format
prepare-for-vision-apiPré-processamento para IA de Visão + estimativa de tokenssource, max_longest_side, quality
faviconGerar conjunto de favicon (ico + png)source, output_dir
compare-imagesComparar duas imagens (MSE/SSIM/diff)source1, source2, metric
collageUnir imagenssources[], direction, gap
instagram-splitDividir em carrossel do Instagramsource, tiles, ratio
social-media-cropCortar com zonas segurassource, platform

Exemplos de Uso

Peça à sua IA em linguagem natural — ela chamará a ferramenta certa automaticamente:

Você DizFerramenta Chamada
"Comprima esta imagem para menos de 200KB"compress
"Converta este PNG para WebP"convert
"Redimensione esta foto para 1200px de largura"resize
"Gere todos os tamanhos de favicon a partir deste logotipo"favicon
"Quais cores estão nesta imagem?"extract-colors
"Otimize isto para o meu site"optimize-for-web
"Prepare esta imagem para GPT-4 Vision"prepare-for-vision-api
"Divida esta imagem em uma grade 3x3"split-image
"Compare estas duas capturas de tela"compare-images
"Obtenha os metadados desta imagem"metadata
"Una estas imagens horizontalmente"collage
"Converta isto para base64"image-to-base64
"Redimensione e comprima em lote estas 10 imagens"batch
"Divida isso para um carrossel do Instagram"instagram-split
"Corte isso para minha capa do Facebook"social-media-crop
