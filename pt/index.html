Perguntas Frequentes

O processamento de imagens é seguro?

Absolutamente seguro. Todo o processamento é feito localmente no seu navegador. As imagens nunca são enviadas para nenhum servidor, garantindo sua privacidade e segurança de dados.

Quais formatos de imagem são suportados?

Suportamos todos os principais formatos de imagem: JPG, JPEG, PNG, WebP, GIF, BMP, SVG, cobrindo a maioria das necessidades de processamento de imagens.

Existe algum limite de tamanho de arquivo?

Não há um limite rígido, mas imagens muito grandes (acima de 100MB) podem ser afetadas pelas limitações de memória do navegador. Recomendamos manter imagens individuais abaixo de 50MB para a melhor experiência.

Posso processar múltiplas imagens de uma vez?

Sim! Você pode selecionar múltiplas imagens de uma vez para processamento em lote. Cada imagem é processada independentemente, e você pode baixá-las individualmente ou todas de uma vez.
