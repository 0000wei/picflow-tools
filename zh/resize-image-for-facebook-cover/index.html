常见问题

为什么我的 Facebook 封面在移动端被裁剪了？

Facebook 封面在桌面端（820×312px）和移动端（640×360px）有不同的尺寸。移动端视图是对图片进行更窄更高的居中裁剪。桌面端靠近左右边缘的内容在移动端会被裁掉。本工具会高亮显示两种设备上都可见的安全区域。

Facebook 封面照片的最佳尺寸是多少？

Facebook 建议桌面端使用 820×312 像素。但为确保封面在所有设备上看起来都很好，建议在 560×312px 的安全区内设计。本工具输出的就是完整的 820×312px 封面，但可帮助你定位安全区内的内容。

我的个人资料图片会遮住部分封面照片吗？

是的！在桌面端，你的个人资料图片（160×160px）会重叠在封面照片的左下角。请避免将重要文字或人脸放在那里。在移动端，个人资料图片位于封面之上，不会重叠。

我可以不用注册使用这个工具吗？

当然可以。无需注册——只需上传图片，定位到安全区，然后下载即可。所有处理都在你的浏览器本地完成，保护隐私。

支持哪些文件格式？

你可以上传 JPG、PNG 和 WebP 格式的图片。工具输出 PNG（无损，文件较大）或 JPG（文件较小，轻微质量损失）。根据需要选择即可。

为什么上传后我的 Facebook 封面变模糊了？

Facebook 会对上传的图片进行压缩。为减少模糊，建议使用高分辨率源图（至少 1640×624px，推荐尺寸的两倍）。本工具输出的是 Facebook 的确切尺寸，但清晰的源图有助于保持 Facebook 压缩后的质量。

什么是 Facebook 封面照片安全区？

安全区（560×312px）是桌面端和移动端视图的交集。放置在此区域内的内容在所有设备上都完全可见。本工具中高亮的绿色区域就是你应该放置重要内容的位置。
