PicEte MCP 集成指南

在 Claude Code、Cursor、Claude Desktop 或任何兼容 MCP 的 AI 客户端中使用 PicEte 图片处理工具。

什么是 MCP？

模型上下文协议（Model Context Protocol，MCP）是一项开放标准，允许 AI 代理（如 Claude Code、Cursor）直接调用外部工具。借助 picete-mcp，您的 AI 可以处理图片——压缩、转换、缩放、提取颜色——无需离开终端，也无需上传到任何服务器。

所有处理均通过 Sharp 在本地完成，零数据离开您的机器。与 PicEte 相同的隐私保障。

快速开始

一条命令即可安装并运行（无需注册，无需配置即可测试）：

npx -y picete-mcp

npm 包：picete-mcp@1.0.0

平台配置

将以下内容添加到您的 AI 客户端的 MCP 配置中：

Claude Desktop

编辑 claude_desktop_config.json：

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Cursor

编辑项目根目录下的 .cursor/mcp.json：

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Claude Code

编辑 ~/.claude/settings.json：

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

可用工具

picete-mcp 提供 13 个工具，分为两类：

原子工具

工具功能关键参数
convert格式转换source, format (jpeg/png/webp/gif), quality
resize缩放图片source, width, height, fit, keep_aspect_ratio
compress压缩文件大小source, quality, target_format, max_size_bytes
extract-colors提取主色调source, color_count（默认 5）
image-to-base64转换为 base64/数据 URLsource, format, data_url
split-image分割为网格瓦片source, rows, cols, overlap_px
metadata获取图片元数据source
batch链式执行多个操作sources[], operations[]

智能工具

工具功能关键参数
optimize-for-web一键网页优化source, max_width, quality, output_format
prepare-for-vision-apiAI 视觉预处理 + Token 估算source, max_longest_side, quality
favicon生成 favicon 全套（ico + png）source, output_dir
compare-images比较两张图片（MSE/SSIM/差异图）source1, source2, metric
collage拼接多张图片sources[], direction, gap
instagram-split分割为Instagram轮播图source, tiles, ratio
social-media-crop使用安全区裁剪source, platform

开发构建

# 克隆并构建
git clone https://github.com/0000wei/picete-mcp.git
cd picete-mcp
npm install
npm run build

# 启动 MCP 服务器
npm start
