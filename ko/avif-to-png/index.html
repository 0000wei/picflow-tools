왜 우리의 AVIF PNG 변환기를 사용해야 할까요?

⚡

WASM 기반 디코딩

Vips 라이브러리의 WebAssembly 포트인 wasm-vips를 사용하여 브라우저에서 AVIF 파일을 정확하게 디코딩합니다. 서버 업로드가 필요 없고 호환성 걱정도 없습니다.

🎯

무손실 PNG 출력

PNG는 재압축 아티팩트 없이 디코딩된 AVIF의 모든 픽셀을 보존합니다. 이미지의 보관, 편집 또는 추가 처리에 완벽합니다.

📦

일괄 처리

일괄 변환을 위해 한 번에 여러 AVIF 파일을 선택하세요. 각 이미지는 독립적으로 처리되며 한 번의 클릭으로 모두 다운로드할 수 있습니다.

🔒

개인 정보 보호

모든 변환은 브라우저에서 로컬로 진행됩니다. AVIF 이미지는 절대 서버에 업로드되지 않습니다. 파일은 항상 기기에 남아 있습니다.

무료 온라인으로 AVIF를 PNG로 변환하는 방법

AVIF 파일 업로드

업로드 영역을 클릭하거나 AVIF 이미지를 브라우저로 끌어다 놓으세요. 이 도구는 image/avif MIME 타입의 .avif 파일을 허용합니다. 한 번에 여러 파일을 선택하여 일괄 변환할 수 있습니다. 파일을 놓으면 파일 이름과 크기가 있는 각 AVIF 이미지의 미리보기를 보여주는 썸네일이 표시됩니다. 모든 처리는 브라우저 내에서 이루어지며 파일은 기기를 벗어나지 않습니다.

wasm-vips로 변환

"PNG로 변환" 버튼을 클릭하여 시작하세요. 도구는 WebAssembly 기반 vips 라이브러리를 로드(처음 사용할 때 잠시 걸릴 수 있음)하고 각 AVIF 이미지를 원시 픽셀 데이터로 디코딩합니다. 출력은 무손실 PNG 파일로 작성됩니다. Canvas 기반 도구와 달리 이 접근 방식은 HDR 메타데이터, 넓은 색 영역 및 알파 투명도를 포함한 모든 AVIF 기능을 올바르게 처리합니다. 각 파일의 변환이 완료되면 진행 표시기가 알려줍니다.

PNG 다운로드

각각 변환된 PNG에는 파일 크기와 미리보기가 표시됩니다. 파일별 버튼을 클릭하여 개별적으로 다운로드하거나, "모든 PNG 다운로드"를 클릭하여 모든 변환된 파일의 순차 다운로드를 트리거합니다. (브라우저가 자동으로 하나씩 처리합니다). 더 많은 변환을 원하시면 "더 많은 이미지 변환"을 클릭하여 새 작업을 시작하세요. 전체 작업은 빠르고 로컬에서 수행되며 개인 정보를 보호합니다.

AVIF를 PNG로 변환하기 팁

왜 AVIF를 PNG로 변환해야 할까요?

AVIF는 뛰어난 압축률을 자랑하는 최신 형식이지만 아직 모든 소프트웨어와 플랫폼에서 지원되는 것은 아닙니다. PNG로 변환하면 호환성이 보장됩니다. 사실상 모든 이미지 뷰어, 편집기 및 웹 브라우저가 PNG를 기본적으로 엽니다. 또한 PNG는 도구 간 무손실 픽셀 데이터를 전달해야 하는 편집 작업에 선호되는 형식입니다. 소셜 미디어 공유나 AVIF 업로드를 거부하는 문서에 포함할 경우 PNG는 신뢰할 수 있는 대안입니다.

PNG 파일 크기 대 AVIF

PNG 파일이 AVIF 원본보다 훨씬 커질 것으로 예상하십시오. AVIF는 비슷한 품질의 JPEG보다 50% 이상 더 나은 압축을 제공하는 반면, PNG는 모든 픽셀을 손실 없이 저장합니다. 500KB의 AVIF 사진이 PNG로 변환되면 3–5MB가 될 수 있습니다. 이는 정상적이고 예상되는 일입니다. 저장을 위해서는 AVIF 원본을 보관하고, 범용적인 호환성이나 무손실 편집 기능이 필요할 때만 PNG를 사용하십시오.

언제 AVIF를 사용하고 언제 PNG를 사용할까

두 형식의 장점을 모두 취하려면 AVIF를 기본 저장 형식(작은 파일, 우수한 품질)으로 유지하고, 광범위한 호환성이 필요할 때마다 필요에 따라 PNG로 변환하십시오. AVIF는 웹 전송 및 아카이브에 이상적입니다. PNG는 AVIF를 지원하지 않을 수 있는 고객이나 동료에게 전송하거나, 그래픽 디자인 소프트웨어로 가져오거나, AVIF를 디코딩하지 못하는 도구에서 편집하거나, 무손실 데이터가 중요한 인쇄를 할 때 최적입니다.

자주 묻는 질문

품질 저하 없이 AVIF 이미지를 PNG로 변환할 수 있나요?

네. PNG는 무손실 형식이므로 픽셀 데이터가 정확히 보존됩니다. 하지만 AVIF 자체는 인코딩 중에 내부적으로 손실 압축을 사용합니다. 디코딩된 AVIF에서 PNG로의 변환은 무손실입니다 — 즉, AVIF에서 보이는 것이 추가적인 품질 저하 없이 그대로 PNG에 담깁니다.

왜 다른 도구처럼 캔버스(Canvas)를 사용해 변환할 수 없나요?

대부분의 브라우저는 캔버스를 통해 AVIF 이미지를 디코딩할 수 없습니다. AVIF는 전용 디코딩 라이브러리가 필요한 비교적 새로운 형식입니다. 저희 도구는 Vips 이미지 처리 라이브러리의 WebAssembly 포트인 wasm-vips를 사용하여 브라우저 내에서 AVIF를 디코딩합니다. 이를 통해 서버에 파일을 업로드하지 않고도 광범위한 호환성과 정확한 디코딩을 보장합니다.

AVIF 파일의 투명도가 PNG에서도 보존되나요?

네. AVIF는 알파 투명도를 지원하며 PNG 역시 이를 지원합니다. 투명한 영역이 있는 AVIF 이미지를 PNG로 변환하면 투명도가 완전히 보존됩니다. 이것은 투명도를 전혀 처리할 수 없는 JPG와 같은 형식에 비해 갖는 중요한 장점입니다.

AVIF를 PNG로 변환할 때 파일 크기 제한이 있나요?

엄격한 파일 크기 제한은 없지만, WebAssembly를 사용하여 브라우저에서 로컬로 변환이 이루어지기 때문에 매우 큰 이미지는 처리하는 데 시간이 더 걸리고 메모리를 많이 차지할 수 있습니다. 20MB 미만의 일반적인 웹 이미지의 경우 변환 속도가 빠릅니다. 파일은 절대 업로드되지 않으며 모든 것이 사용자 기기에서 처리됩니다.
