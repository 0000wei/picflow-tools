개인정보 보호

🎨

여러 이미지를 동시에 업로드하고 처리하여 작업 흐름을 획기적으로 개선합니다.

AI 지원: 모든 AI 에이전트에서 PicEte 사용

PicEte는 이제 MCP (Model Context Protocol) 서버로 작동합니다 — Claude Code, Cursor, Claude Desktop과 같은 AI 코딩 에이전트가 브라우저를 열지 않고도 명령줄에서 직접 PicEte 도구를 호출할 수 있습니다.

빠른 시작
# 설치 및 실행 (가입 불필요)
npx -y picete-mcp

# Claude Code ~/.claude/settings.json에 설정:
# {
#   "mcpServers": {
#     "picete": {
#       "command": "npx",
#       "args": ["-y", "picete-mcp"]
#     }
#   }
# }

그런 다음 AI에게 "이 이미지 압축해줘", "이것을 WebP로 변환해줘", 또는 "이 로고에서 파비콘 생성해줘"라고 요청하세요.

자주 묻는 질문

이미지 처리는 안전한가요?

완전히 안전합니다. 모든 처리는 브라우저에서 로컬로 이루어집니다. 이미지는 어떤 서버에도 업로드되지 않으며, 개인정보와 데이터 보안을 보장합니다.

어떤 이미지 형식을 지원하나요?

JPG, JPEG, PNG, WebP, GIF, BMP, SVG 등 모든 주요 이미지 형식을 지원하며, 대부분의 이미지 처리 요구를 충족합니다.

파일 크기 제한이 있나요?

엄격한 제한은 없지만, 매우 큰 이미지(100MB 이상)는 브라우저 메모리 제한의 영향을 받을 수 있습니다. 최상의 경험을 위해 개별 이미지를 50MB 이하로 유지하는 것을 권장합니다.

여러 이미지를 한 번에 처리할 수 있나요?

네! 여러 이미지를 한 번에 선택하여 일괄 처리할 수 있습니다. 각 이미지는 독립적으로 처리되며, 개별적으로 또는 모두 한 번에 다운로드할 수 있습니다.
