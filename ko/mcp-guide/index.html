PicEte MCP 연동 가이드

Claude Code, Cursor, Claude Desktop 또는 기타 MCP 호환 AI 클라이언트에서 PicEte의 이미지 처리 도구를 사용하세요.

MCP란 무엇인가요?

모델 컨텍스트 프로토콜(MCP)은 AI 에이전트(예: Claude Code, Cursor)가 외부 도구를 직접 호출할 수 있게 해주는 오픈 표준입니다. picete-mcp를 사용하면 AI가 터미널을 벗어나거나 서버에 업로드하지 않고도 이미지를 처리(압축, 변환, 크기 조정, 색상 추출)할 수 있습니다.

모든 처리는 Sharp를 통해 로컬에서 실행됩니다. 어떤 데이터도 기기 외부로 전송되지 않습니다. PicEte와 동일한 개인정보 보호를 보장합니다.

빠른 시작

단일 명령어로 설치 및 실행하세요 (테스트를 위한 가입이나 설정이 필요하지 않습니다):

npx -y picete-mcp

npm 패키지: picete-mcp@1.0.0

플랫폼 설정

AI 클라이언트의 MCP 설정에 다음을 추가하세요:

Claude Desktop

claude_desktop_config.json 수정:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Cursor

프로젝트 루트의 .cursor/mcp.json 수정:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Claude Code

~/.claude/settings.json 수정:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

사용 가능한 도구

picete-mcp는 두 가지 카테고리에 걸쳐 13개의 도구를 제공합니다:

원자 단위 도구(Atomic Tools)

도구기능주요 매개변수
convert형식 변환source, format (jpeg/png/webp/gif), quality
resize이미지 크기 조정source, width, height, fit, keep_aspect_ratio
compress파일 크기 압축source, quality, target_format, max_size_bytes
extract-colors주요 색상 추출source, color_count (기본 5)
image-to-base64base64/data URL로 변환source, format, data_url
split-image그리드 타일로 분할source, rows, cols, overlap_px
metadata이미지 메타데이터 가져오기source
batch여러 작업 체이닝(일괄 처리)sources[], operations[]

스마트 도구(Smart Tools)

도구기능주요 매개변수
optimize-for-web원클릭 웹 최적화source, max_width, quality, output_format
prepare-for-vision-apiAI 비전 전처리 + 토큰 예측source, max_longest_side, quality
favicon파비콘 세트(ico + png) 생성source, output_dir
compare-images두 이미지 비교(MSE/SSIM/diff)source1, source2, metric
collage이미지 이어 붙이기sources[], direction, gap
instagram-split인스타그램 캐러셀로 분할source, tiles, ratio
social-media-crop안전 영역으로 자르기source, platform

사용 예시

자연어로 AI에게 요청하세요 — 자동으로 올바른 도구를 호출합니다:

요청 예시호출되는 도구
"이 이미지를 200KB 이하로 압축해 줘"compress
"이 PNG를 WebP로 변환해 줘"convert
"이 사진을 가로 1200px로 크기 조정해 줘"resize
"이 로고로 모든 크기의 파비콘을 생성해 줘"favicon
"이 이미지에 어떤 색상이 있니?"extract-colors
"내 웹사이트에 맞게 최적화해 줘"optimize-for-web
"GPT-4 Vision용으로 이 이미지를 준비해 줘"prepare-for-vision-api
"이 이미지를 3x3 그리드로 분할해 줘"split-image
"이 두 스크린샷을 비교해 줘"compare-images
"이 이미지의 메타데이터를 가져와 줘"metadata
"이 이미지들을 가로로 이어 붙여 줘"collage
"이것을 base64로 변환해 줘"image-to-base64
"이 10개 이미지를 일괄 크기 조정하고 압축해 줘"batch
"인스타그램 캐러셀을 위해 이것을 분할해줘"instagram-split
"내 페이스북 커버를 위해 이것을 잘라줘"social-media-crop

개발

# 클론 및 빌드
git clone https://github.com/0000wei/picete-mcp.git
cd picete-mcp
npm install
npm run build

# MCP 서버 시작
npm start
