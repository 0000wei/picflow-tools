دليل تكامل PicEte MCP

استخدم أدوات معالجة الصور من PicEte من Claude Code وCursor وClaude Desktop أو أي عميل ذكاء اصطناعي متوافق مع MCP.

ما هو MCP؟

بروتوكول سياق النموذج (MCP) هو معيار مفتوح يسمح لوكلاء الذكاء الاصطناعي (مثل Claude Code وCursor) باستدعاء الأدوات الخارجية مباشرة. مع picete-mcp، يمكن للذكاء الاصطناعي الخاص بك معالجة الصور — ضغط، تحويل، تغيير الحجم، استخراج الألوان — دون مغادرة الطرفية ودون تحميل أي شيء إلى أي خادم.

جميع المعالجة تتم محليًا عبر Sharp. لا تغادر أي بيانات جهازك. نفس ضمان الخصوصية كما في PicEte.

بداية سريعة

قم بالتثبيت والتشغيل بأمر واحد (لا حاجة للتسجيل، ولا حاجة لتكوين للاختبار):

npx -y picete-mcp

npm الحزمة: picete-mcp@1.0.0

تكوين المنصات

أضف ما يلي إلى تكوين MCP لعميل الذكاء الاصطناعي الخاص بك:

Claude Desktop

قم بتحرير claude_desktop_config.json:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Cursor

قم بتحرير .cursor/mcp.json في جذر مشروعك:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

Claude Code

قم بتحرير ~/.claude/settings.json:

{
  "mcpServers": {
    "picete": {
      "command": "npx",
      "args": ["-y", "picete-mcp"]
    }
  }
}

الأدوات المتاحة

يوفر picete-mcp 13 أداة في فئتين:

الأدوات الذرية

الأداةالوظيفةالمعاملات الرئيسية
convertتحويل التنسيقsource, format (jpeg/png/webp/gif), quality
resizeتغيير حجم الصورةsource, width, height, fit, keep_aspect_ratio
compressضغط حجم الملفsource, quality, target_format, max_size_bytes
extract-colorsاستخراج الألوان السائدةsource, color_count (الافتراضي 5)
image-to-base64تحويل إلى base64/رابط بياناتsource, format, data_url
split-imageتقسيم إلى شبكة من المربعاتsource, rows, cols, overlap_px
metadataالحصول على بيانات الصورة الوصفيةsource
batchتسلسل عمليات متعددةsources[], operations[]

الأدوات الذكية

الأداةالوظيفةالمعاملات الرئيسية
optimize-for-webتحسين الويب بنقرة واحدةsource, max_width, quality, output_format
prepare-for-vision-apiمعالجة مسبقة لرؤية الذكاء الاصطناعي + تقدير الرموزsource, max_longest_side, quality
faviconإنشاء مجموعة أيقونات المفضلة (ico + png)source, output_dir
compare-imagesمقارنة صورتين (MSE/SSIM/الفرق)source1, source2, metric
collageتجميع الصور معًاsources[], direction, gap
instagram-splitتقسيم إلى منصة إنستغرام الدوارةsource, tiles, ratio
social-media-cropقص مع مناطق آمنةsource, platform

التطوير

# Clone and build
git clone https://github.com/0000wei/picete-mcp.git
cd picete-mcp
npm install
npm run build

# Start the MCP server
npm start
