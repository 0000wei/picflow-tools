Frequently Asked Questions

Is this really free?

Yes, 100% free. No ads, no limits, no upgrade prompts. PicEte is a brand extension of PicEte.com — supported by our free online image tools.

Does my data leave my server?

No. All compression happens locally using PHP extensions or CLI tools. Zero external API calls. Your images never leave your site.

Can I optimize my existing media library?

Yes. Use the Bulk Optimize button in Media Library. It processes images using cursor-based pagination — handles tens of thousands of images without timeout.

How does it compare to TinyPNG?

Our Imagick-based quantizer achieves similar savings for most PNG images (50-70%). For maximum compression, the plugin auto-detects and uses pngquant if installed on your server — the same algorithm TinyPNG uses.

What about backups?

Original images are automatically backed up before compression. Backups are stored in a protected directory (uploads/picete-backups/) with .htaccess deny rules. Configurable retention (days + max total storage).

Does it support next-gen formats?

Yes. Automatic WebP conversion for all image sizes (thumbnail through full). The plugin also reinvents HTML to serve WebP via <picture> tags when supported by the browser.
