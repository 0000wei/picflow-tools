# 韩语版 (ko) 全量翻译 SPEC

## 任务背景
项目现正在拓展韩语版（ko）。目前 `/ko/` 目录群（共计 50 个 HTML 文件，包括首页和各工具页）已经创建完毕，但内部的文案仍为英文母版内容。我们需要你对这 50 个文件执行英文到韩文（ko）的本地化翻译。

## 任务要求
1. **翻译范围**：
   - 翻译 `ko/` 目录下所有 `.html` 文件中对用户可见的英文内容，包括但不限于：`<title>`, `<meta name="description">`, `<h1>` ~ `<h6>`, `<p>`, `<li>`, `<button>`, `<a>` 标签文本，以及 FAQ 内容、JS 脚本中涉及界面提示的文字。
2. **严禁修改项（不做的）**：
   - **绝对不能修改任何 HTML 标签的结构、类名 (class)、ID。**
   - **绝对不能翻译或修改 `<script>` 内的配置项 JSON（如 `var names = {...}`）。**
   - **不能更改图片的 `src` 属性，也不能修改 `href` 的链接层级（前面我已经修改好 /ko/ 的路由）。**
3. **分批执行建议**：
   - 因为涉及 50 个 HTML 文件，单次请求容易超出输出上限或被截断，请务必自行在内部规划分批次读取和覆写。建议每次只处理 5~10 个文件，直至处理完所有 `ko/**/*.html`。
4. **Harness 验证**：
   - 保证 50 个 HTML 的结构完整性，不能有闭合标签缺失。

## 完成标准
所有 `/ko/` 目录下的 `.html` 文件中的用户可见文本都被准确翻译为韩语，且项目的排版与功能依然 100% 正常工作。
