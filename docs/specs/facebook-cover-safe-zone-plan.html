项目概况

在现有 /zh/resize-image-for-facebook-cover/ 页面位置上，从 0 构建一个具备完整交互功能的"安全区裁剪工具"。核心功能包含上传、拖拽/缩放、安全区遮罩渲染、桌面/移动端沉浸式 UI 预览、JPG/PNG 导出。纯前端零上传，保持 picete 一贯风格。

架构决策：这是 picete 迄今为止交互复杂度最高的工具。所有渲染逻辑集中在 1 个 JS 文件 (js/facebook-cover.js) + 1 个 HTML 模板。不引入框架依赖，纯 Canvas 2D API。

全部用 Claude Code 以 stdin 管道方式执行。任务按依赖顺序分组。每个 Task 完成即验证，不批量提交。

Group B: 核心交互引擎 (5 Task)

这是产品核心。每个 Task 需端到端验证（浏览器打开确认）。

#Task描述估算依赖
4 B1 — 上传模块 实现 Canvas 上的图片加载：拖拽（drag/drop events）、点击（hidden input）、Ctrl+V（paste event）。支持 JPG/PNG/WebP。图片加载后居中显示在 1200x628 画布上。显示加载状态。 M A1, A2
5 B2 — 拖拽/缩放控制 鼠标拖拽平移图片（mousedown/mousemove/mouseup）和滚轮缩放（wheel event）+ 滑块控制。限制最小/最大缩放比例。图片不能超出画布边缘（边界约束）。 M B1
6 B3 — 安全区遮罩渲染 核心功能。在 Canvas 上渲染三层：① 底层原图 ② 半透明黑色遮罩（盖住非安全区域）③ 高亮安全区矩形。计算逻辑按照 PRD：桌面可见区 820x312（水平带）、移动端可见区 560x628（垂直带）、绝对安全区为两者交集。辅助 3x3 网格。 L B2
7 B4 — 预览切换 三个切换按钮：[所有设备安全区] | [桌面端预览] | [移动端预览]。桌面端/移动端预览模式隐藏安全区遮罩，显示模拟 Facebook UI 界面（假头像、白边、操作按钮、返回按钮、搜索框）。UI 图层按等比例覆盖在图片上。 XL B3
8 B5 — 导出下载 HTML5 Canvas 导出为 JPG (quality 0.92) 或 PNG。输出尺寸 1200x628。下载按钮文案"Download Facebook Cover Photo"。 S B3
B4 注意事项：沉浸式 UI 模拟需要精确绘制 Facebook 桌面/移动端界面元素。建议参考真实 Facebook 页面截图，绘制简化的 UI 线框图。不需要逐像素还原，但要能产生"就是 Facebook 页面"的视觉感受。

验证标准

  1. 所有 8 语种页面在 HTTP 服务器上正常渲染，无 404
  2. 上传功能：拖拽、点击、Ctrl+V 三种方式均可用
  3. 拖拽/缩放：图片可在 Canvas 内平滑移动和缩放
  4. 安全区遮罩：半透明黑色覆盖非安全区域，高亮区域正确
  5. 预览切换：三种模式切换正确，沉浸式 UI 可见
  6. 导出：下载的 JPG/PNG 尺寸为 1200x628，内容正确
  7. 移动端适配：<768px 响应式布局正常，触控操作可用
  8. 暗色模式：所有 UI 元素在 light/dark 下均可读
  9. hreflang/canonical：每个页面指向正确的语言版本
  10. 结构化数据：WebApplication + BreadcrumbList + FAQPage JSON-LD 有效
