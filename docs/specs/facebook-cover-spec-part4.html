10.1 模板：B3 安全区遮罩（L 级任务）

You are implementing part of the Facebook Cover Safe Zone Cropper tool for PicEte.com.

## File to modify
Create or modify: js/facebook-cover.js (all language versions share this file)

## What to implement — B3: Render safe zone overlay on Canvas

### Context
Existing files already created: resize-image-for-facebook-cover/index.html, css/style.css updated.
JS file already has: upload function (B1) and drag/zoom (B2) implemented.

### Canvas constants (use these exactly)
- CANVAS_WIDTH = 1200, CANVAS_HEIGHT = 628
- DESKTOP_VISIBLE: top=155, height=312 (covers full width 1200)
- MOBILE_VISIBLE: left=320, width=560 (covers full height 628)
- SAFE_ZONE = intersection: left=320, top=155, width=560, height=312

### Render pipeline (called from requestAnimationFrame loop)
function render() {
  1. ctx.clearRect(0, 0, 1200, 628)
  2. Draw user image at current offset/scale (ctx.drawImage(img, offsetX, offsetY, w*scale, h*scale))
  3. Based on state.mode:
     mode='safe':
       a. Draw 3x3 grid (2 horizontal lines at y=209, y=418; 2 vertical at x=400, x=800)
          color: rgba(255,255,255,0.4), stroke width 0.5
       b. Draw 4 overlay rectangles covering non-safe-zone:
          ctx.fillStyle = 'rgba(0,0,0,0.55)'
          - top: (0,0)→(1200,155)
          - bottom: (0,467)→(1200,628)
          - left: (0,155)→(320,467)
          - right: (880,155)→(1200,467)
       c. Draw safe zone border: stroked rect (320,155,560,312) 2px #6366F1

     mode='desktop':
       a. Draw top overlay (0,0→1200,155) and bottom overlay (0,476→1200,628)
          fillStyle rgba(0,0,0,0.6)
       b. Call drawDesktopUI() — but that's B4, for now leave blank

     mode='mobile':
       a. Draw left overlay (0,0→320,628) and right overlay (880,0→1200,628)
          fillStyle rgba(0,0,0,0.6)
       b. Call drawMobileUI() — but that's B4, for now leave blank
}

### Behavior
- render() is called every frame via requestAnimationFrame
- render() is called: on image load, on each mouse move/drag, on each wheel zoom, on slider change, on mode change
- The "mode" is controlled by preview-btn click handlers that set state.mode
- Export (download) uses a SEPARATE offscreen canvas with NO overlays — just the image at current offset/scale

### Validation
- Safe mode: dark overlay visible, only center 560x312 px bright
- Desktop mode: only center horizontal band visible (top + bottom cut)
- Mobile mode: only center vertical band visible (left + right cut)
- All modes show the user image underneath correctly
