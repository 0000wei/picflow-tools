1. 产品全景

一句话产品定义：上传一张封面图，通过拖拽/缩放将其放入"安全区"，预览桌面端和移动端真实效果，然后下载完美适配的 Facebook 封面图。

用户痛点：Facebook 封面在桌面端（宽扁）和移动端（窄高）展示方式完全不同 + 头像/按钮遮挡 = 反复返工。

技术约束：纯前端零上传（Canvas 2D API）。所有处理在浏览器本地完成。

输出图片：1200 × 628 px（推荐上传尺寸），JPG 或 PNG 格式。

版本说明：这是 PRD 中的"第一阶段 MVP"，不包含第二阶段的智能背景填充、封面类型切换等功能。

3.2 上传流程

  1. 初始状态：显示上传区域（与 picete 其他工具一致的虚线框）。提示：拖拽图片 / 点击选择 / Ctrl+V 粘贴
  2. 支持格式：JPG、PNG、WebP
  3. 加载后：图片居中显示在画布上。如果图片纵横比 ≠ 1.91:1，图片以"cover"模式填充画布（等比缩放裁剪）或"contain"模式显示（等比缩放留白）。
    默认策略：cover 模式（填满画布不留白，超出部分被裁剪），因为这是 Facebook 封面的实际行为。
  4. 错误处理：非图片文件显示提示"请选择有效的图片文件"；超过 20MB 显示警告，但仍然允许尝试。

3.3 拖拽平移

  • 触发：鼠标在 Canvas 上按下（mousedown）→ 移动（mousemove）→ 松开（mouseup）
  • 行为：图片在画布内移动。图片边缘不能完全退出画布（必须有边界约束——图片的至少一个像素始终在画布内）
  • 光标：grab（默认）→ grabbing（拖拽中）
  • 边界约束算法：
    offsetX = clamp(dx, -(imgWidth * scale - canvasWidth), 0)
    offsetY = clamp(dy, -(imgHeight * scale - canvasHeight), 0)
  • 性能：requestAnimationFrame 节流。不连续重绘导致闪烁。

3.4 缩放控制

  • 方法 1：鼠标滚轮（wheel event）—— 以鼠标位置为缩放中心点
  • 方法 2：滑块（range input）—— 以画布中心为缩放中心点
  • 缩放范围：0.25x – 5x（步进 0.01）
  • 默认缩放：cover 模式下，默认 scale = max(canvasWidth/imgWidth, canvasHeight/imgHeight)
  • 滚轮缩放中心点：
    // 缩放前记下鼠标下的图像坐标
    const imgX = (mouseX - offsetX) / oldScale
    const imgY = (mouseY - offsetY) / oldScale
    // 缩放后重新计算 offset
    offsetX = mouseX - imgX * newScale
    offsetY = mouseY - imgY * newScale
  • 滑块刻度：显示百分比，精确到整数百分比。

3.5 触控支持（移动端）

  • 单指拖拽：touchstart / touchmove / touchend — 计算单指移动距离平移图片
  • 双指缩放：计算两个 touch 点之间的距离变化。distance = hypot(t1.x-t2.x, t1.y-t2.y)。scale *= (newDist / oldDist)。默认缩放中心为两点中点。
  • 防止页面滚动：touchstart 和 touchmove 调用 e.preventDefault() 防止页面随拖拽而滚动。

3.6 预览切换

三个按钮，一次只能选一个（单选组 UI，圆点指示当前选中）：

按钮对应状态显示效果
📱 所有设备安全区mode = 'safe' (默认)画布上渲染半透明遮罩 + 亮色矩形安全区高亮 + 3x3 网格
💻 桌面端预览mode = 'desktop'切换到沉浸式桌面 UI 模拟：应用桌面端裁剪框 + 假头像 + 按钮 + 返回栏
📱 移动端预览mode = 'mobile'切换到沉浸式移动 UI 模拟：应用移动端裁剪框 + 手机框 + 假头像 + 操作按钮
预期行为差异：safe 模式下用户看到的是"蓝色安全区 + 深色遮罩"的工具感。desktop/mobile 模式下应该让用户觉得"这就是 Facebook 页面上的样子"。
