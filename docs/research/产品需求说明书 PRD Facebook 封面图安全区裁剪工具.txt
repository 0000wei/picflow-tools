产品需求说明书 (PRD)：Facebook 封面图安全区裁剪工具

1. 产品背景与目标
1.1 产品背景
Facebook 的封面图展示机制非常特殊：同一张图片在桌面端（宽扁）和移动端（窄高）的裁剪方式完全不同。此外，左下角的个人/主页头像以及底部的操作按钮会遮挡大部分关键信息。常规的图片调整工具只能改变图片尺寸，无法预览这些遮挡区域，导致用户上传后发现文字被裁或人脸被挡，需要反复返工。

1.2 核心目标
打造一个“所见即所得”的 Facebook 封面图制作工具。用户上传图片后，不仅能一键调整为官方推荐尺寸，还能通过“安全区遮罩”直观地看到图片在真实 Facebook 页面上的展示效果，确保核心信息完全可见。

2. 核心规格与安全区参数
这是前端绘图与遮罩渲染的核心逻辑：

画布基础尺寸 (最佳上传尺寸)：建议采用 1200 x 628 像素（高分辨率推荐）或 820 x 462 像素 作为底层画布，以保证跨设备的高清显示。

桌面端可见区 (Desktop View)：显示画布的中间水平带，上下两边会被系统裁剪。

移动端可见区 (Mobile View)：显示画布的中间垂直带，左右两边会被系统裁剪。

绝对安全区 (Safe Zone)：中间的核心区域。这是桌面端和移动端交汇的区域，无论用户用什么设备，这里的图像都不会被边缘裁剪。

UI 遮挡区 (UI Overlay)：

左下角/正下方的圆形头像遮挡（区分个人主页和公共主页的头像位置）。

底部的渐变阴影及操作按钮（如“关注”、“发消息”）。

3. 第一阶段：MVP 核心功能需求
3.1 核心工作台 (Editor)
这是用户停留时间最长的页面，交互需极度流畅。

图层与操作：

用户上传图片后，图片应在画布（Canvas）内居中显示。

支持用户鼠标拖拽（移动位置）、滚轮或滑块（放大/缩小）图片。

辅助参考线与遮罩 (核心亮点)：

安全区高亮：默认用半透明黑色遮罩盖住非安全区，高亮显示中间的绝对安全区。

辅助网格：提供 3x3 网格辅助构图。

设备预览切换 (Preview Toggles)：

在工作台上方或下方提供切换按钮：[所有设备安全区] | [桌面端预览] | [移动端预览]。

当点击“桌面端/移动端预览”时，工作台直接模拟套用 Facebook 的真实 UI 界面（加上假的头像、白边和假名字），让用户产生极强的代入感。

3.2 导入与导出模块
上传：支持拖拽上传、点击上传、Ctrl+V 粘贴图片。支持 JPG, PNG, WEBP 格式。

导出下载：

按钮文案使用明确的引导，例如：“下载 Facebook 封面图”。

直接在前端通过 HTML5 Canvas 导出 JPG 或 PNG，无需经过服务器处理（提升速度并降低服务器成本）。

输出的图片尺寸必须精准符合 Facebook 的最佳标准。

3.3 页面结构与 SEO 布局
这个页面承载着获取自然搜索流量的重任，建议直接在现有的 /resize-image-for-facebook-cover/ URL 上进行升级。

H1 标题：Free Facebook Cover Maker & Safe Zone Cropper

核心内容模块 (置于工具下方)：

使用教程：3步图文说明（1. 上传 -> 2. 拖拽至安全区 -> 3. 下载）。

尺寸科普：用图文并茂的方式向用户解释最新 Facebook 桌面端与移动端封面尺寸差异。

FAQ：解答诸如“为什么我的 Facebook 封面在手机上会被切掉？”等常见问题，利用真实痛点命中长尾关键词。

3.4 交互与体验设计 (UI/UX)
无缝体验：不需要用户注册或登录即可使用全部功能。

直观的 UI 元素：使用类似 Figma 或 Photoshop 裁剪工具的暗色半透明遮罩，突出高亮保留区域。

移动端适配：必须支持手机端双指捏合缩放（Pinch-to-zoom）。界面变为上下结构：上方为工作台，下方为控制滑块和预览切换按钮。

4. 第二阶段：体验升级与场景拓展 (增强版)
4.1 智能背景填充 (Smart Background Fill)
痛点：用户上传了一张比例不符的图片，缩小到安全区后，画布两侧会留出大片空白。

功能需求：

高斯模糊填充 (Gaussian Blur)：自动复制原图，放大并进行深度模糊处理，填满背景空白处。

智能取色填充：分析图片边缘或主色调，提供一键填充相近纯色背景的功能。

自定义颜色/透明底：允许用户手动选择十六进制颜色，或选择导出带有透明背景（PNG）的图片。

4.2 沉浸式设备 UI 预览 (Immersive Device Preview)
痛点：用户虽然看到了“安全区”，但仍然缺乏对最终效果的直观想象。

功能需求：在“真实 UI 视图”下，将用户的图片置于底层，上层覆盖一层按等比例还原的 Facebook 桌面端和移动端 UI 透明图层（包含虚拟的返回按钮、搜索框、左下角头像、点赞评论按钮等），让用户彻底确认不会被遮挡。

4.3 Facebook 全场景尺寸支持
痛点：Facebook 不仅有个人主页封面，群组和活动的尺寸及遮挡区完全不同。

功能需求：在工具栏增加“Facebook 封面类型”下拉菜单，切换时自动调整底图比例和安全区遮罩：

Personal Profile Cover（个人主页封面）

Business Page Cover（公共主页封面）

Facebook Group Cover（群组封面）

Facebook Event Cover（活动封面）

5. 第三阶段：流量裂变与生态联动 (增长版)
5.1 跨平台一键适配 (Omni-Channel Resize)
痛点：用户做好了 Facebook 封面，通常还需要更新 Twitter (X) 和 LinkedIn。

功能需求：在下载成功页面，提供“继续操作”按钮，带着当前的图片参数，直接跳转到 Twitter 等其他平台的安全区裁剪工具页面，增加 PV 和工具粘性。

5.2 社交分享与闭环引流
功能需求：下载完成后，弹出轻量级的分享提示。提供一键分享到社交平台的按钮，默认文案附带品牌词和网址（例如："Just created a perfectly fitted Facebook cover without any cropped text using Picete! 🚀 [URL]"）。

5.3 用户项目历史 (本地存储)
功能需求：利用浏览器的 LocalStorage 或 IndexedDB，自动保存用户最近编辑的图片和参数。用户下次访问时可直接从“最近项目”恢复编辑，提升回访留存率。

6. 第四阶段：AI 赋能与高级能力 (护城河阶段)
6.1 AI 智能主体居中 (AI Subject Auto-Framing)
功能需求：用户上传图片后，前端或后端自动识别图片中的“人脸”或“核心物品”，并自动将其缩放、平移至绝对安全区内，实现真正的“零点击自动适配”。

6.2 批量处理模式 (Batch Mode)
功能需求：允许社交媒体代运营人员一次性拖入多张图片，统一套用设定的安全区模板并批量导出 ZIP 压缩包，满足专业级高频需求。
