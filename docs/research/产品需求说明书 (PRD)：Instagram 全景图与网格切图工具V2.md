# 产品需求说明书 (PRD)：Instagram 全景图与网格切图工具

> 版本：V2.1 | 日期：2026-06-09 | 状态：Draft → Spec Ready

---

## 1. 产品概述与业务目标

### 1.1 产品背景

Instagram 平台有两类刚需视觉排版：

- **无缝轮播图 (Seamless Carousel)**：将宽幅长图切分成多张，用户滑动时呈现完整长卷。
- **主页九宫格 (Profile Grid)**：将大图切分为 3×N 网格，占据个人主页头部海报位。

由于 Instagram 原生不支持切割，用户常面临切割比例不对、边缘不齐、导出顺序混乱等痛点。

### 1.2 核心目标

为内容创作者提供"傻瓜式"在线切图工具。用户上传图片、选择模式、拖拽选区后，一键生成完美适配 IG 比例的图片包，并按发布顺序正确命名打包。完全在浏览器端本地处理，极速且隐私安全。

## 2. 系统集成与路由架构

新工具需无缝接入 PicEte 现有 60+ 工具生态体系。

### 2.1 文件路径与骨架规范

| 项 | 规范 |
|----|------|
| HTML 路径 | `/instagram-image-splitter/index.html`（英文主页面） |
| CSS/JS | 复用全局样式；专属逻辑放 `/assets/js/tools/instagram-splitter.js` |
| HTML 骨架 | 必须继承 PicEte 标准模板：Top Navbar → Theme Toggle → Language Switcher → Footer → GA |
| Navbar 入口 | 注册到 "Social Media Tools" 下拉菜单分类 |

### 2.2 国际化 (i18n) 与 Vercel 路由

**首发语言**：en, zh, ja, de, fr, es, pt, ar。ar 环境下 UI 布局必须支持 RTL (direction: rtl)。

**vercel.json rewrite 规则**：
```json
{
  "cleanUrls": true,
  "trailingSlash": true,
  "rewrites": [
    { "source": "/instagram-image-splitter", "destination": "/instagram-image-splitter/index.html" },
    { "source": "/:lang(zh|ja|de|fr|es|pt|ar)/instagram-image-splitter", "destination": "/:lang/instagram-image-splitter/index.html" }
  ]
}
```

## 3. 核心功能与参数规格

### 3.1 模式一：全景轮播 (Carousel / Panorama)

| 参数 | 值 |
|------|-----|
| 切片数量 | 2 ~ 10 张（滑块或下拉选择） |
| 单张比例 | **4:5**（默认/推荐，选框整体宽高比 = `(4 × N) : 5`）、**1:1**（选框宽高比 = `N : 1`） |

### 3.2 模式二：主页网格 (Profile Grid)

| 参数 | 值 |
|------|-----|
| 排版 | 固定 3 列，支持 3×1(3张)、3×2(6张)、3×3(9张)、3×4(12张) |
| 单张比例 | 强制 1:1（Instagram 主页缩略图固定为正方形） |
| 选框宽高比 | `3 : 行数` |

## 4. 技术架构与底层处理

| 项 | 规范 |
|----|------|
| 处理引擎 | HTML5 Canvas，纯浏览器端，不上传服务器 |
| 内存管理 | 上传图片后使用 `URL.createObjectURL(file)` 读取；重新上传或离开页面时**必须**调用 `URL.revokeObjectURL()` 显式释放 |
| 大图降采样 | 图片**最长边** > 4096px 时，在离屏 Canvas 中等比例降采样，限制最长边为 4096px，防止 iOS Safari 崩溃 |
| 导出格式 | `canvas.toDataURL('image/jpeg', 0.92)`。原图含透明通道时，先在 Canvas 上填充纯白背景 (#FFFFFF) 再切割 |
| 预览反馈 | 降采样发生时，在控制面板区域显示非阻塞提示："原图已自动压缩至 4096px 以保证兼容性" |

## 5. 交互细节与 UI/UX

### 5.1 界面布局 (UI Mockup)

桌面端左右分栏，移动端上下分栏响应式布局。

```
[ 顶部标准 Navbar & 多语言 & 主题切换 ]
----------------------------------------------------------
[ 左侧/上方：控制面板 ]       | [ 右侧/下方：工作台 (Canvas) ]
- 模式切换：[滑动轮播] [主页网格] |  +-------------------------+
- 切片数量：[ 滑块 2 ~ 10 ]     |  |     [ 原图变暗背景 ]      |
- 比例选择：[ 4:5 ] [ 1:1 ]   |  |   +------------------+   |
- 操作按钮：[重置裁剪框]         |  |   | 1 | 2 | 3 | 4 |   |  <- 裁剪框与切割线高亮
- 导出按钮：[下载 ZIP]         |  |   +------------------+   |
---------------------------  |  |                         |
                             |  +-------------------------+
```

### 5.2 裁剪框操作逻辑

| 行为 | 规则 |
|------|------|
| 初始位置 | 上传后裁剪框默认居中，以图片短边为基准自适应填充 |
| 缩放 | 拖拽四角，强制同比缩放 (Aspect Ratio Locked)，不可形变 |
| 边界 | 裁剪框绝对不可超出原图物理边界 |
| 平移 | 鼠标/手指在裁剪框内部按下即可拖拽 |
| 切割线视觉 | `box-shadow: inset 0 0 0 1px rgba(255,255,255,0.8), inset 0 0 0 2px rgba(0,0,0,0.5)`——任何底色下清晰可见 |

## 6. 验收标准 (Acceptance Criteria)

| ID | 描述 | 来源 |
|----|------|------|
| AC-1 | 宽高比精度：4:5 比例、N 切片时，最终选框宽高比 = (4×N) : 5，误差 ≤ ±1px | V2 原有 |
| AC-2 | ZIP 命名与顺序：导出的 ZIP 无嵌套文件夹，文件命名严格 `picete-[mode]-[index].jpg`。Grid 模式左上角 = 1，右下角 = 行数×3 | V2 原有 |
| AC-3 | 移动端降级：CSS Media Query ≤768px 时，ZIP 按钮下方出现逐张保存长图流 + 提示文案 | V2 原有 |
| AC-4 | 切割完整性：全景模式下将生成的 N 张图片横向无缝拼接，必须与原图裁剪框区域完全一致（像素级对齐） | **V2.1 新增** |
| AC-5 | 网格比例：Grid 模式下每张单图为精确 1:1 正方形，误差 ≤ ±1px | **V2.1 新增** |
| AC-6 | 文件大小：单张导出 JPG ≤ 800KB，适配 Instagram 上传限制 | **V2.1 新增** |

## 7. 测试计划 (Test Strategy)

| 用例 | 描述 | 验收标准 |
|------|------|----------|
| 极端全景图 | 上传 10:1 宽高比全景图，验证生成 10 张 4:5 裁剪框不越界 | 裁剪框完全位于图片边界内，每张切片比例正确 |
| 极小图片 | 上传 < 300×300px 图片 | 前端 UI 显示错误拦截，不进入裁剪流程 |
| 内存泄漏 | 连续替换上传 10 张不同 10MB 原图 | 手动触发 GC 后，JS Heap 增量 ≤ 5MB |
| 多终端 | iOS Safari、Chrome for Android、桌面 Chrome/Firefox/Safari | 所有核心功能正常 |

## 8. 迭代规划 (Phase Map)

- **Phase 1 (MVP)**：核心切图功能——全景轮播 + 主页网格 + ZIP 导出 + 移动端降级。这是首批实现的全部范围。
- **Phase 2**：接缝放大镜 (Seam Magnifier)——用户点击切割线时 200% 比例放大接缝处，提供 1px 级别微调按钮。*不在 MVP 中实现。*
- **Phase 3**：生态引流——下载后弹出"一键适配 Facebook 封面"转化按钮。Reverse Grid 另立独立工具。*不在本页面实现。*
