5. colours 参数排查

测试图片: test-photo-320x240.png (124 KB)

colours位深PNG 合法?结果大小节省
2568-bit✅✅22.9 KB-81.6%
1287-bit❌❌ IHDR Error——
646-bit❌❌ IHDR Error——
325-bit❌❌ IHDR Error——
164-bit✅✅13.0 KB-89.5%
83-bit❌❌ IHDR Error——

21-bit✅✅2.1 KB-98.3%
Q-only自动✅✅22.9 KB-81.6%
📌 根源： PNG 格式标准定义 IHDR（图像头）的 bit_depth 字段仅允许 1/2/4/8/16 bit 五种值。256 色=8-bit、16 色=4-bit、4 色=2-bit、2 色=1-bit 是唯一合法的组合。128/64/32/8 色对应的 7/6/5/3 bit 在 PNG 规范中不存在。

这不是 libimagequant 缺失。 Q-only 模式正确工作证明底层量化器存在。libvips 的 palette: true + Q 参数让量化器自行决定色数并匹配合法位深。

测试循环数结果
连续压缩 + delete (变 Q 值模拟滑块拖动)50 次✅ 50/50 零泄漏
✅ 确认： vips.Image.newFromBuffer() + image.delete() 模式在 50 次连续调用中无内存泄漏。此模式可直接用于 Web Worker。 
// 已验证的安全模式（Phase 0.1/0.2 使用）
let image;
try {
  image = vips.Image.newFromBuffer(uint8Array);
  const output = image.writeToBuffer('.png', { palette: true, Q: 80, effort: 7 });
  // ... 使用 output ...
} finally {
  if (image) image.delete();
}
